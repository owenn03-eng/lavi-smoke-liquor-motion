# Lavi Smoke & Liquor — Motion Pass

## Stack

- Static HTML + Tailwind CDN
- Lenis smooth scroll
- GSAP + ScrollTrigger
- CSS 3D glass showcase
- Images loaded from the static redesign CDN (`lavi-smoke-liquor.vercel.app/img/…`)
